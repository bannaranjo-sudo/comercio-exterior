
# Plan de Desarrollo

## Fase 1 - Fundamentos
- Inicializar Next.js con TypeScript.
- Configurar Tailwind CSS y shadcn/ui.
- Preparar PostgreSQL y Prisma.
- Implementar autenticación.
- Configurar empresas, usuarios y permisos.
- Crear dashboard y menú lateral.

## Fase 2 - Operaciones
- Crear importaciones y exportaciones.
- Registrar terceros y productos.
- Administrar estados y responsables.
- Implementar historial de actuaciones.

## Fase 3 - Logística
- Gestionar embarques.
- Registrar navieras y transportadoras.
- Administrar contenedores.
- Registrar puertos, rutas y fechas.
- Controlar entregas.

## Fase 4 - Gestión documental
- Adjuntar documentos por operación.
- Controlar documentos pendientes.
- Registrar revisiones y versiones.

## Fase 5 - Costos e inventarios
- Registrar gastos por operación.
- Calcular costos estimados y reales.
- Gestionar bodegas e inventarios.
- Registrar entradas y salidas.

## Fase 6 - Analítica
- Crear indicadores gerenciales.
- Implementar reportes.
- Configurar alertas.
- Exportar información.

## Estado actual
- Fases 1 y 2 completadas; fase 3 (seguimiento básico), fase 4 y fase 5 (costos) cubiertas por el MVP: ver `docs/MVP.md`.
- Pendiente: contenedores y navieras, versiones de documentos, inventarios, reportes y alertas.

## Reglas de ejecución
- Desarrollar una fase a la vez.
- Dividir cada fase en tareas pequeñas.
- Verificar cada funcionalidad antes de continuar.
- Mantener el código documentado y versionado.
- No implementar funcionalidades fuera del alcance aprobado.
